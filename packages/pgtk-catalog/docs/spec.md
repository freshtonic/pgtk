# pgtk-catalog implementation spec

This is the contract that implementation work is written against. Vocabulary
is in `CONTEXT.md`. Rationale is in `docs/design.md` and `docs/adr/`. When
this file and those disagree, fix this file, do not silently diverge.

Conventions for all code:

- Edition 2024, MSRV 1.88, `missing_docs = deny`, `unsafe_code = forbid`,
  `clippy::all = warn`. Every public item has a doc comment.
- Doc comments and prose use ASD-STE100 style: short sentences, active
  voice, one idea per sentence, no em-dashes.
- `#[cfg_attr(feature = "serde", derive(serde::Serialize, serde::Deserialize))]`
  on every model type. Nothing else in the core is feature-gated.
- Required dependency: `thiserror` only.
- Rust names in this file are normative. Do not rename.

## 2. Primitives

```rust
/// A PostgreSQL object identifier. Display prints the number.
#[derive(Debug, Clone, Copy, PartialEq, Eq, Hash, PartialOrd, Ord)]
pub struct Oid(pub u32);

/// A typed index into one Catalog's arena for `T`.
pub struct Handle<T>(u32, PhantomData<fn() -> T>);
// Manual impls (not derives, to avoid bounds on T): Debug ("Handle<Type>(12)"),
// Clone, Copy, PartialEq, Eq, Hash, PartialOrd, Ord.
// serde: serialize/deserialize as a bare u32.
impl<T> Handle<T> {
    /// Only the builder and loader construct handles.
    pub(crate) fn new(index: u32) -> Self;
    /// The raw arena index.
    pub fn index(self) -> u32;
}

/// An identifier as the server stores it: already case-folded, unquoted.
/// Equality is byte equality. Display prints it raw, without quoting.
#[derive(Debug, Clone, PartialEq, Eq, Hash, PartialOrd, Ord)]
pub struct Name(String);
impl Name { pub fn new(s: impl Into<String>) -> Self; pub fn as_str(&self) -> &str; }
impl From<&str> for Name; impl From<String> for Name;
impl PartialEq<str> for Name; impl PartialEq<&str> for Name;  // Oid: From<u32>
impl Borrow<str> for Name; impl AsRef<str> for Name; impl Deref<Target = str> for Name;

/// A Schema name and an entity name.
#[derive(Debug, Clone, PartialEq, Eq, Hash)]
pub struct QualifiedName { pub schema: Name, pub name: Name }
impl QualifiedName { pub fn new(schema: impl Into<Name>, name: impl Into<Name>) -> Self; }
// Display: "schema.name", no quoting.
```

## 3. Model types

Entities are plain public structs with public fields so consumers can
pattern-match. They are not `#[non_exhaustive]`; adding a field is a breaking
change, and that is accepted.

```rust
pub struct Schema {
    pub oid: Oid, pub name: Name,
    /// True for the temporary schema (`pg_temp_N`) of the loader's session.
    /// At most one per catalog. `#[serde(default)]`, so a file without it loads.
    pub is_temporary: bool,
    pub extension: Option<Handle<Extension>>,
}

pub struct Extension { pub oid: Oid, pub name: Name, pub version: String, pub schema: Handle<Schema> }

pub struct Type {
    pub oid: Oid,
    pub name: Name,
    pub schema: Handle<Schema>,
    pub category: TypeCategory,
    pub is_preferred: bool,
    pub is_collatable: bool,          // typcollation <> 0
    /// typcollation. None when 0, and when the collation is not kept (with a
    /// MissingReference). `default` (OID 100) for a collatable base type.
    pub collation: Option<Handle<Collation>>,   // #[serde(default)]
    pub array: Option<Handle<Type>>,  // typarray, None for array types and when 0
    pub kind: TypeKind,
    /// From the default btree operator class whose opcintype is this type.
    pub btree: Option<BtreeOperators>,          // #[serde(default)]
    /// Strategy 1 of the default hash operator class whose opcintype is this type.
    pub hash_equality: Option<Handle<Operator>>, // #[serde(default)]
    pub extension: Option<Handle<Extension>>,
}

/// pg_amop strategies 1..5 of a btree, each with the type on both sides.
pub struct BtreeOperators {
    pub lt: Handle<Operator>, pub le: Handle<Operator>, pub eq: Handle<Operator>,
    pub ge: Handle<Operator>, pub gt: Handle<Operator>,
}

pub enum TypeKind {
    Base,
    Array { element: Handle<Type> },
    Composite(CompositeDetail),
    Domain(DomainDetail),
    Enum { labels: Vec<Name> },           // in enumsortorder
    Range(RangeDetail),
    Multirange { range: Handle<Type> },
    Pseudo(PseudoType),
}
pub struct CompositeDetail { pub fields: Vec<Field>, pub relation: Option<Handle<Relation>> }
pub struct Field { pub name: Name, pub ty: Handle<Type>, pub typmod: Typmod }
pub struct DomainDetail { pub base: Handle<Type>, pub typmod: Typmod, pub not_null: bool, pub check_constraints: u32 }
pub struct RangeDetail { pub subtype: Handle<Type>, pub multirange: Handle<Type> }

/// typcategory. Other(c) holds an undocumented letter.
pub enum TypeCategory { Array, Boolean, Composite, DateTime, Enum, Geometric, Network,
    Numeric, Pseudo, Range, String, Timespan, UserDefined, BitString, Unknown, Internal, Other(char) }
// Letters: A B C D E G I N P R S T U V X Z respectively.
impl TypeCategory { pub fn from_char(c: char) -> Self; pub fn as_char(self) -> char; }

/// The 26 pseudo-types of PostgreSQL 14-17, plus Other for a future one.
pub enum PseudoType { Any, AnyElement, AnyArray, AnyNonArray, AnyEnum, AnyRange, AnyMultirange,
    AnyCompatible, AnyCompatibleArray, AnyCompatibleNonArray, AnyCompatibleRange,
    AnyCompatibleMultirange, Record, RecordArray, Cstring, Internal, Void, Unknown, Trigger,
    EventTrigger, LanguageHandler, FdwHandler, IndexAmHandler, TsmHandler, TableAmHandler,
    PgDdlCommand, Other(Name) }
impl PseudoType {
    pub fn from_name(name: &str) -> Self;   // "_record" -> RecordArray; unknown -> Other
    pub fn is_polymorphic(&self) -> bool;   // the Any* family
}

pub struct Relation {
    pub oid: Oid, pub name: Name, pub schema: Handle<Schema>, pub kind: RelationKind,
    pub row_type: Option<Handle<Type>>, pub columns: Vec<Column>,
    /// reloftype: the composite type of `CREATE TABLE t OF type`. None when 0.
    /// Not the row type. For typeIsOfTypedTable in can_coerce_type.
    pub of_type: Option<Handle<Type>>,     // #[serde(default)]
    /// pg_inherits: direct parents in inhseqno order. Empty when none. Covers
    /// INHERITS and partitions. The consumer walks the chain (typeInheritsFrom).
    pub parents: Vec<Handle<Relation>>,    // #[serde(default)]
    pub primary_key: Option<PrimaryKey>,   // #[serde(default)]
    /// pg_get_viewdef(oid, true) for relkind v and m, else None. Not parsed.
    /// The text depends on the search_path of the loader's session.
    /// pg_constraint rows with this conrelid, in name order. Includes the
    /// primary key. `Relation::constraint(name)` finds one.
    pub constraints: Vec<Constraint>,      // #[serde(default)]
    pub view_definition: Option<String>,   // #[serde(default)]
    /// pg_rewrite without the _RETURN rule, in name order.
    pub rules: Vec<Rule>,                  // #[serde(default)]
    /// pg_trigger without internal triggers, in name order.
    pub triggers: Vec<Trigger>,            // #[serde(default)]
    pub extension: Option<Handle<Extension>>,
}

/// pg_collation. No locale data: parse analysis never sorts text.
pub struct Collation {
    pub oid: Oid, pub name: Name, pub schema: Handle<Schema>,
    pub encoding: Option<i32>,           // collencoding; None for -1
    pub provider: CollationProvider,     // collprovider
    pub deterministic: bool,             // collisdeterministic
    pub extension: Option<Handle<Extension>>,
}
pub enum CollationProvider { Default, Libc, Icu, Builtin }   // d c i b (b: PostgreSQL 17)
pub struct Encoding { pub id: i32, pub name: String }        // 6, "UTF8"
impl Encoding {
    pub fn utf8() -> Self;
    /// False for SQL_ASCII (0), EUC_JIS_2004 (5), MULE_INTERNAL (7), WIN874 (21).
    pub fn is_supported_by_icu(&self) -> bool;
    /// lookup_collation: Some(id) needs id == self.id; None is usable, but an
    /// Icu collation also needs is_supported_by_icu().
    pub fn can_use(&self, collation: &Collation) -> bool;
}

pub struct Parameter { pub name: String, pub kind: ParameterKind }   // pg_settings.name, vartype
pub enum ParameterKind { Bool, Integer, Real, String, Enum }
impl ParameterKind { pub fn from_vartype(vartype: &str) -> Option<Self>; }

pub struct Constraint {
    pub name: Name, pub kind: ConstraintKind, pub deferrable: bool,
    pub columns: Vec<i16>,   // conkey; 0 for an expression of an exclusion constraint; may be empty
}
/// contype p u c f x t. No NotNull: PostgreSQL 18 added that row for a relation.
pub enum ConstraintKind { PrimaryKey, Unique, Check, ForeignKey, Exclusion, ConstraintTrigger }
impl ConstraintKind { pub fn has_index(self) -> bool; }   // PrimaryKey | Unique | Exclusion
impl Relation { pub fn constraint(&self, name: &str) -> Option<&Constraint>; }

/// pg_opclass JOIN pg_am. Unique on (schema, name, method).
pub struct OperatorClass {
    pub oid: Oid, pub name: Name, pub schema: Handle<Schema>,
    pub method: Name,               // amname: btree hash gist gin spgist brin ...
    pub input_type: Handle<Type>,   // opcintype
    pub is_default: bool,           // opcdefault
    pub extension: Option<Handle<Extension>>,
}

pub struct Rule {
    pub name: Name, pub event: RuleEvent, pub instead: bool,
    pub unconditional: bool,   // ev_qual::text = '<>' (ev_qual is never NULL)
    pub fires: FiresWhen,      // ev_enabled
    pub definition: String,    // pg_get_ruledef(oid, true); not parsed; #[serde(default)]
}
impl Rule {
    /// event matches, instead, unconditional, and fires.in_origin().
    pub fn replaces(&self, event: RuleEvent) -> bool;
}
/// ev_type 2 3 4. No Select: _RETURN is the only ON SELECT rule the server
/// permits, and view_definition carries it.
pub enum RuleEvent { Update, Insert, Delete }
/// ev_enabled / tgenabled: O R A D.
pub enum FiresWhen { Origin, Replica, Always, Disabled }
impl FiresWhen { pub fn in_origin(self) -> bool; }   // Origin | Always

pub struct Trigger {
    pub name: Name, pub timing: TriggerTiming,
    pub insert: bool, pub update: bool, pub delete: bool, pub truncate: bool,
    pub row_level: bool,
    pub fires: FiresWhen,      // tgenabled; not read by the updatable-view check
}
impl Trigger {
    /// tgtype bits: 1 row, 2 before, 4 insert, 8 delete, 16 update,
    /// 32 truncate, 64 instead.
    pub fn from_tgtype(name: Name, tgtype: i16, fires: FiresWhen) -> Self;
    pub fn is_instead_of_row(&self) -> bool;
}
pub enum TriggerTiming { Before, After, InsteadOf }
impl Relation {
    pub fn column(&self, name: &str) -> Option<&Column>;
    /// By `Column::position` (attnum), not by index: a dropped attribute leaves a gap.
    pub fn column_at(&self, position: i16) -> Option<&Column>;
}
/// pg_constraint with contype = 'p'. No other constraint is in the model.
pub struct PrimaryKey {
    pub columns: Vec<i16>,   // conkey: attribute positions, in key order
    pub deferrable: bool,    // condeferrable
}
impl PrimaryKey {
    /// `None` when deferrable, as in check_functional_grouping
    /// (get_primary_key_attnos with deferrableOk = false).
    pub fn grouping_columns(&self) -> Option<&[i16]>;
}
pub enum RelationKind { Table, View, MaterializedView, ForeignTable, PartitionedTable, Sequence }
// relkind r v m f p S
// A sequence has three columns: last_value int8, log_cnt int8, is_called bool.
// PostgreSQL 14 and later give a sequence no pg_type row (reltype = 0), so
// row_type is None for a Sequence and Some for each other kind.
// The model holds no pg_sequence detail (start, increment, cycle).
pub struct Column {
    pub name: Name, pub position: i16, pub ty: Handle<Type>, pub typmod: Typmod,
    pub not_null: bool, pub has_default: bool, pub generated: bool,
    pub collation: Option<Handle<Collation>>,   // attcollation: None for 0
    pub identity: Option<Identity>,   // attidentity: None for ''
}
/// attidentity. An INSERT or UPDATE of a non-DEFAULT value into an Always
/// column is SQLSTATE 428C9 (without OVERRIDING SYSTEM VALUE); ByDefault
/// accepts each value.
pub enum Identity { Always, ByDefault }   // a d
impl Relation { pub fn column(&self, name: &str) -> Option<&Column>; }

pub struct Function {
    pub oid: Oid, pub name: Name, pub schema: Handle<Schema>, pub kind: FunctionKind,
    pub arguments: Vec<Argument>,           // proallargtypes order, else proargtypes
    pub variadic: Option<Handle<Type>>,     // provariadic when <> 0
    pub default_count: u16,                 // pronargdefaults
    /// exprType() of each proargdefaults expression. len == default_count (the
    /// builder enforces it). The defaults belong to the last default_count
    /// input arguments, in order. An untyped literal for a polymorphic
    /// argument is Some(unknown). None: a node kind the loader does not know,
    /// or a type that is not kept.
    pub default_types: Vec<Option<Handle<Type>>>,   // #[serde(default)]
    pub returns: Handle<Type>, pub returns_set: bool, pub strict: bool,
    pub volatility: Volatility, pub aggregate: Option<AggregateDetail>,
    pub extension: Option<Handle<Extension>>,
}
pub enum FunctionKind { Function, Procedure, Aggregate, Window }   // prokind f p a w
pub struct Argument { pub name: Option<Name>, pub ty: Handle<Type>, pub mode: ArgMode }
pub enum ArgMode { In, Out, InOut, Variadic, Table }                 // i o b v t
pub enum Volatility { Immutable, Stable, Volatile }                 // i s v
pub struct AggregateDetail { pub kind: AggregateKind, pub direct_args: u16 }
pub enum AggregateKind { Normal, OrderedSet, HypotheticalSet }      // n o h
impl Function {
    /// Arguments with mode In, InOut, or Variadic, in order.
    pub fn input_arguments(&self) -> impl Iterator<Item = &Argument>;
}

pub struct Operator {
    pub oid: Oid, pub name: Name, pub schema: Handle<Schema>, pub kind: OperatorKind,
    pub left: Option<Handle<Type>>, pub right: Handle<Type>, pub result: Handle<Type>,
    pub function: Handle<Function>,
    pub commutator: Option<Handle<Operator>>, pub negator: Option<Handle<Operator>>,
    pub extension: Option<Handle<Extension>>,
}
pub enum OperatorKind { Prefix, Infix }   // oprkind l b

pub struct Cast {
    pub oid: Oid, pub source: Handle<Type>, pub target: Handle<Type>,
    pub context: CastContext, pub method: CastMethod, pub extension: Option<Handle<Extension>>,
}
pub enum CastContext { Implicit, Assignment, Explicit }              // i a e
pub enum CastMethod { Function(Handle<Function>), Binary, InOut }    // f b i
```

## 4. Builtin

`src/builtin/generated.rs` is produced by `cargo xtask gen-builtins
<path/to/pg_type.dat>` from PostgreSQL 17.9's `src/include/catalog/pg_type.dat`
(vendored at `../pgtk-sql/vendor/postgres/src/include/catalog/pg_type.dat`).
It contains:

```rust
/// Every Type with a fixed OID that a SQL expression can name.
#[derive(Debug, Clone, Copy, PartialEq, Eq, Hash, PartialOrd, Ord)]
#[repr(u16)]
pub enum Builtin { Bool = 0, Bytea, Char, ... }   // OID order: BoolArray sits at 1000
impl Builtin {
    /// All variants, in discriminant order.
    pub const ALL: &'static [Builtin] = &[...];
    /// The fixed OID.
    pub const fn oid(self) -> Oid;
    /// The `typname`.
    pub const fn name(self) -> &'static str;
}
```

Generation rules:

- One variant per `{ oid => ... }` entry in `pg_type.dat`, plus one per
  `array_type_oid` (the array of that entry).
- Variant name: split `typname` on `_`, capitalise each part, join. A
  leading underscore (array) or an `array_type_oid` entry appends `Array`.
  `"char"` is `typname => 'char'` and becomes `Char`. `bpchar` stays
  `Bpchar`. Examples: `int4` -> `Int4`, `_int4` -> `Int4Array`,
  `timestamptz` -> `Timestamptz`, `pg_lsn` -> `PgLsn`, `int2vector` ->
  `Int2vector`, `_record` -> `RecordArray`.
- Order: by OID ascending. Discriminants are contiguous from 0 so
  `Builtin::ALL[b as usize] == b`.
- Header comment names the source file and says the file is generated.
- Expected count for 17.9: 112 entries plus 81 arrays, 193 variants.

Hand-written in `src/builtin.rs`: `impl Builtin { pub fn from_oid(Oid) -> Option<Builtin> }`
(binary search over a const sorted table or a match).

## 5. Typmod

```rust
/// A raw type modifier. -1 means "none".
#[derive(Debug, Clone, Copy, PartialEq, Eq, Hash)]
pub struct Typmod(pub i32);
impl Typmod {
    pub const NONE: Typmod = Typmod(-1);
    pub fn is_none(self) -> bool;   // true for every negative value
    /// Decode for a Built-in Type. None when NONE or when the type has no typmod.
    pub fn decode(self, builtin: Builtin) -> Option<TypmodDetail>;
}
pub enum TypmodDetail {
    /// bpchar, varchar: typmod - 4 (VARHDRSZ).
    CharLength(u32),
    /// numeric: precision ((t-4)>>16)&0xffff, scale (((t-4)&0x7ff)^1024)-1024.
    Numeric { precision: u16, scale: i16 },
    /// bit, varbit: typmod is the length.
    BitLength(u32),
    /// time, timetz, timestamp, timestamptz: typmod is the fractional-second precision.
    TimePrecision(u8),
    /// interval: precision = t & 0xffff (0xffff => None), fields = t >> 16 (0x7fff => None).
    Interval { fields: Option<IntervalFields>, precision: Option<u8> },
}
/// Raw interval field mask from `utils/timestamp.h`. Constants exposed: YEAR 1<<2, MONTH 1<<1,
/// DAY 1<<3, HOUR 1<<10, MINUTE 1<<11, SECOND 1<<12.
pub struct IntervalFields(pub u16);
impl IntervalFields { pub fn contains(self, mask: u16) -> bool; }
```

Only the builtins listed above decode; every other Builtin returns None.
Array types do not decode (typmod applies to the element; the consumer
handles that).

## 6. Catalog

```rust
pub struct ServerVersion { pub major: u16, pub minor: u16 }
// From server_version_num: major = n / 10000, minor = n % 10000. Display "17.2".

pub struct Metadata {
    pub server_version: ServerVersion,
    pub database: Name,
    pub encoding: Encoding,         // pg_database.encoding; serde default UTF8
    pub search_path: Vec<Name>,     // current_schemas(true) at load
    pub loaded_at_unix_secs: u64,
    pub format_version: u32,        // == Catalog::FORMAT_VERSION at build time
}
impl Metadata { pub fn placeholder() -> Self; }  // version 0.0, database "placeholder", empty path, 0

pub struct Catalog { /* private: arenas, metadata, builtins, indexes */ }
impl Catalog {
    pub const FORMAT_VERSION: u32 = 3;   // 2: Type gained btree and hash_equality
                                         // 3: Relation gained primary_key
                                         // 4: Column.identity became Option<Identity>
                                         // 5: Relation gained parents, Function gained default_types
                                         // 6: Relation gained of_type
                                         // 7: Relation gained view_definition, rules, triggers
                                         // 8: Catalog gained parameters
                                         // 9: collations; Type.collation, Column.collation, Metadata.encoding
                                         // 10: Relation.constraints, operator classes, Rule.definition
    pub fn metadata(&self) -> &Metadata;

    // Built-ins
    pub fn builtin(&self, b: Builtin) -> Handle<Type>;          // panics if absent (see builder)
    pub fn try_builtin(&self, b: Builtin) -> Option<Handle<Type>>;
    pub fn as_builtin(&self, h: Handle<Type>) -> Option<Builtin>; // by OID

    // Iteration, OID order. Each yields (Handle<T>, &T).
    pub fn schemas(&self) -> impl ExactSizeIterator<Item = (Handle<Schema>, &Schema)>;
    pub fn extensions(&self) -> ...; pub fn types(&self) -> ...; pub fn relations(&self) -> ...;
    pub fn functions(&self) -> ...; pub fn operators(&self) -> ...; pub fn casts(&self) -> ...;

    // By OID
    pub fn schema_by_oid(&self, oid: Oid) -> Option<Handle<Schema>>;
    // same: extension_by_oid, type_by_oid, relation_by_oid, function_by_oid, operator_by_oid, cast_by_oid

    // By name
    pub fn schema_named(&self, name: &str) -> Option<Handle<Schema>>;
    /// The temporary schema of the loader's session, if it had one.
    pub fn temporary_schema(&self) -> Option<Handle<Schema>>;
    pub fn extension_named(&self, name: &str) -> Option<Handle<Extension>>;
    pub fn type_named(&self, name: &QualifiedName) -> Option<Handle<Type>>;
    pub fn relation_named(&self, name: &QualifiedName) -> Option<Handle<Relation>>;
    /// All overloads with this qualified name, OID order.
    pub fn functions_named(&self, name: &QualifiedName) -> &[Handle<Function>];
    pub fn operators_named(&self, name: &QualifiedName) -> &[Handle<Operator>];

    // By unqualified name and search path
    pub fn type_visible(&self, path: &SearchPath, name: &str) -> Option<Handle<Type>>;
    pub fn relation_visible(&self, path: &SearchPath, name: &str) -> Option<Handle<Relation>>;
    /// Every candidate in search-path order, then OID order within a schema.
    /// The hiding rule (identical signature in an earlier schema) is the consumer's.
    /// Both skip a temporary schema: PostgreSQL never searches `pg_temp` for a
    /// function or an operator. A qualified name still finds one.
    pub fn functions_visible(&self, path: &SearchPath, name: &str) -> Vec<Handle<Function>>;
    pub fn operators_visible(&self, path: &SearchPath, name: &str) -> Vec<Handle<Operator>>;

    // Sort operators (what get_sort_group_operators reads). Exact type only:
    // no domain base type, no binary-coercible type, no anyarray / anyenum /
    // anyrange / anymultirange / record fallback. Those rules are the
    // consumer's. The pseudo-types themselves do have an answer.
    pub fn btree_ordering(&self, ty: Handle<Type>) -> Option<BtreeOperators>;
    pub fn hash_equality(&self, ty: Handle<Type>) -> Option<Handle<Operator>>;

    // Relationships
    /// The stored cast from `from` to `to`, if any.
    pub fn cast(&self, from: Handle<Type>, to: Handle<Type>) -> Option<Handle<Cast>>;
    /// Casts whose source is `from`, OID order.
    pub fn casts_from(&self, from: Handle<Type>) -> &[Handle<Cast>];

    // Operator classes. An arena like the others: operator_classes(),
    // operator_class_by_oid, Index<Handle<OperatorClass>>,
    // qualified_name_of_operator_class. The key is (schema, name, method).
    pub fn operator_class_named(&self, name: &QualifiedName, method: &str) -> Option<Handle<OperatorClass>>;
    pub fn operator_class_visible(&self, path: &SearchPath, name: &str, method: &str) -> Option<Handle<OperatorClass>>;

    // Collations. An arena like the others: collations(), collation_by_oid,
    // Index<Handle<Collation>>, qualified_name_of_collation.
    /// Every row with this name, for each encoding, OID order.
    pub fn collations_named(&self, name: &QualifiedName) -> &[Handle<Collation>];
    /// The row that metadata().encoding can use: a row for that encoding
    /// first, then a row for each encoding.
    pub fn collation_named(&self, name: &QualifiedName) -> Option<Handle<Collation>>;
    /// First schema on the path with a usable row (CollationGetCollid). A
    /// schema with the name only for another encoding does not stop the walk.
    pub fn collation_visible(&self, path: &SearchPath, name: &str) -> Option<Handle<Collation>>;

    // Configuration parameters (pg_settings). Not an arena: no OID, no handle.
    /// Sorted by the ASCII-lower-case name.
    pub fn parameters(&self) -> &[Parameter];
    /// ASCII-case-insensitive, as guc_name_compare. Gives the canonical spelling.
    pub fn parameter(&self, name: &str) -> Option<&Parameter>;
    pub fn qualified_name_of_type(&self, h: Handle<Type>) -> QualifiedName;
    // same for relation, function, operator
}
impl Index<Handle<Schema>> for Catalog { type Output = Schema; }
// and for Extension, Type, Relation, Function, Operator, Cast.
```

Catalog is `Send + Sync`, `Debug`, and `Clone`. It holds no `Rc`, `RefCell`,
or interior mutability. `SearchPath` is `Debug + Clone + PartialEq + Eq`;
`AggregateDetail` is `Copy`.
Indexes are `HashMap`s built once by the builder. Name-keyed maps are keyed
by `(Handle<Schema>, Name)`.

serde: `Catalog` serializes as a private `CatalogData { metadata, schemas,
extensions, types, relations, functions, operators, casts }`. Deserialize
rebuilds indexes and builtins through the builder path, and fails if
`metadata.format_version != Catalog::FORMAT_VERSION` or the builtin check
fails (see `fixture`).

```rust
pub struct SearchPath { /* private: Vec<Handle<Schema>> */ }
```

## 8. CatalogBuilder

```rust
pub struct CatalogBuilder { ... }
impl CatalogBuilder {
    pub fn new(metadata: Metadata) -> Self;
    /// Start from an existing Catalog (typically the Fixture) and add to it.
    pub fn from_catalog(catalog: Catalog) -> Self;
    /// Permit `finish` to succeed with Built-in Types absent. Tests only.
    pub fn permit_missing_builtins(&mut self) -> &mut Self;

    // Each push returns the handle the entity will have. Handles are the
    // push order; the loader pushes in OID order to satisfy design.md.
    pub fn push_schema(&mut self, s: Schema) -> Handle<Schema>;
    pub fn push_extension(&mut self, e: Extension) -> Handle<Extension>;
    pub fn push_type(&mut self, t: Type) -> Handle<Type>;
    pub fn push_relation(&mut self, r: Relation) -> Handle<Relation>;
    pub fn push_function(&mut self, f: Function) -> Handle<Function>;
    pub fn push_operator(&mut self, o: Operator) -> Handle<Operator>;
    pub fn push_cast(&mut self, c: Cast) -> Handle<Cast>;
    pub fn push_parameter(&mut self, p: Parameter);   // no handle
    pub fn push_collation(&mut self, c: Collation) -> Handle<Collation>;
    pub fn push_operator_class(&mut self, c: OperatorClass) -> Handle<OperatorClass>;
    /// The handle the next push_type will return (for forward references in cycles).
    pub fn next_type_handle(&self) -> Handle<Type>;
    pub fn next_relation_handle(&self) -> Handle<Relation>;
    pub fn next_operator_handle(&self) -> Handle<Operator>;
    /// Patch an entity already pushed (to close a cycle).
    pub fn type_mut(&mut self, h: Handle<Type>) -> &mut Type;
    pub fn relation_mut(&mut self, h: Handle<Relation>) -> &mut Relation;
    pub fn operator_mut(&mut self, h: Handle<Operator>) -> &mut Operator;

    pub fn finish(self) -> Result<Catalog, BuildError>;
}
#[derive(Debug, thiserror::Error)]
pub enum BuildError {
    #[error("{entity} handle {index} is out of range (arena has {len})")]
    DanglingHandle { entity: &'static str, index: u32, len: u32 },
    #[error("duplicate OID {oid} in {entity} arena")]
    DuplicateOid { entity: &'static str, oid: Oid },
    #[error("built-in type {builtin:?} (oid {oid}) is missing")]
    MissingBuiltin { builtin: Builtin, oid: Oid },
    /// A primary key names a position that no column of the relation has.
    UnknownKeyColumn { relation: Oid, position: i16 },
    /// default_types.len() != default_count.
    DefaultTypesLength { function: Oid, default_count: u16, default_types: usize },
    /// Two parameters with one ASCII-lower-case name.
    DuplicateParameter { name: String },
}
```

`finish` validates every handle in every entity is in range, that OIDs are
unique per arena, and that every `Builtin` resolves unless permitted. Then it
builds indexes. `from_catalog` re-opens the arenas; the metadata is kept.

## 9. Diagnostics and errors

```rust
#[derive(Debug, Clone, PartialEq, Eq)]
#[non_exhaustive]
pub enum Diagnostic {
    /// typtype not in b c d e p r m.
    UnknownTypeKind { oid: Oid, name: Name, typtype: char },
    /// An entity referenced an OID that is not in the catalog (or was itself skipped).
    MissingReference { entity: EntityKind, oid: Oid, name: Name, referenced: EntityKind, referenced_oid: Oid },
    /// A row value could not be interpreted; the entity was skipped.
    UnparsableValue { entity: EntityKind, oid: Oid, column: &'static str, value: String },
    /// Skipped for a stated reason (e.g. shell operator with no function).
    Skipped { entity: EntityKind, oid: Oid, name: Name, reason: SkipReason },
}
pub enum EntityKind { Schema, Extension, Type, Relation, Column, Function, Operator, Cast, OperatorClass, Rule, Trigger, Parameter, Collation, Constraint }
#[non_exhaustive]
pub enum SkipReason { ShellOperator, DependsOnSkipped, UnsupportedRelationKind(char), IncompleteOperatorClass }
impl Display for Diagnostic;
// EntityKind has as_str() and Display; SkipReason has Display.

#[derive(Debug, thiserror::Error)]
pub enum LoadError {
    #[error("server version {0} is not supported; need 14 through 17")]
    UnsupportedVersion(ServerVersion),
    #[error("query {query:?} failed: {source}")]
    Query { query: QueryId, #[source] source: Box<dyn std::error::Error + Send + Sync> },
    #[error("query {query:?} was never fed to the loader")]
    MissingRows { query: QueryId },
    #[error("query {query:?} row {row} column {column}: cannot parse {value:?}")]
    Parse { query: QueryId, row: usize, column: usize, value: String },
    #[error(transparent)]
    Build(#[from] BuildError),
}
```

`Parse` is fatal only for columns whose failure means the query is wrong
(OIDs, booleans, version, a "one letter" cell that is not one character).
Per-entity oddities, such as an unknown letter in `prokind` or
`castmethod`, become `UnparsableValue` diagnostics and skip that entity.
A pseudo-type wins over `is_array`, so `_record` is `Pseudo(RecordArray)`.

## 10. Loader (sans-IO)

```rust
/// Rows of one query; every cell is the text form, None for SQL NULL.
pub type Rows = Vec<Vec<Option<String>>>;
pub struct Loaded { pub catalog: Catalog, pub diagnostics: Vec<Diagnostic> }

#[derive(Debug, Clone, Copy, PartialEq, Eq, Hash)]
pub enum QueryId { Version, Database, SearchPath, Schemas, Extensions, ExtensionMembers,
    Types, EnumLabels, Relations, Attributes, Functions, FunctionArguments, Aggregates,
    Operators, Casts, DefaultOperatorClasses, PrimaryKeys, Inherits, Rules, Triggers,
    Parameters, Collations, Constraints, OperatorClasses }
impl QueryId { pub const ALL: &'static [QueryId]; }

pub struct Loader { ... }
impl Loader {
    /// SQL that returns one row, one column: server_version_num as text.
    pub const BOOTSTRAP_QUERY: &'static str;
    pub fn new(bootstrap_rows: Rows) -> Result<Self, LoadError>;
    pub fn version(&self) -> ServerVersion;
    /// Every query still to run, with its SQL text. Order is irrelevant.
    /// `Version` is omitted because the bootstrap row already answered it.
    pub fn queries(&self) -> impl Iterator<Item = (QueryId, &'static str)>;
    pub fn feed(&mut self, query: QueryId, rows: Rows);
    /// Fails with MissingRows if any query was not fed.
    pub fn finish(self) -> Result<Loaded, LoadError>;
}
```

The SQL for each query is version-independent across 14 through 17. Every
selected column is cast to `text`. `Loader::new` still records the version
for `Metadata` and for future divergence. Booleans arrive as `t`/`f`: the
SQL spells each boolean as `(CASE WHEN x THEN 't' ELSE 'f' END)::text`,
because `bool::text` yields `true`/`false`. `regproc` columns (`oprcode`,
`aggfnoid`) are cast `::oid::text`, because `regproc::text` yields a name.
`scripts/check-queries.sh` extracts each query through a marker convention
documented in `queries.rs`; keep that shape when editing SQL.

### Query definitions (column order is the contract)

Schema filter used everywhere: `nspname NOT LIKE 'pg\_toast%' AND (nspname
NOT LIKE 'pg\_temp%' OR oid = pg_catalog.pg_my_temp_schema())` via a join on
`pg_namespace`. It keeps the session's own temporary schema and drops those of
other sessions. `pg_my_temp_schema()` is 0 when the session has none.
`pg_toast_temp_N` matches `pg\_toast%`, so it stays out.

- **Version**: `SELECT current_setting('server_version_num')`.
- **Database**: `datname, encoding, pg_encoding_to_char(encoding)` from
  `pg_database WHERE datname = current_database()`.
- **SearchPath**: `SELECT s::text FROM unnest(current_schemas(true)) WITH ORDINALITY AS t(s, n) ORDER BY n`.
- **Schemas**: `oid, nspname, (oid = pg_my_temp_schema()) AS is_temporary` from
  `pg_namespace` with the filter, `ORDER BY oid`.
- **Extensions**: `oid, extname, extversion, extnamespace` `ORDER BY oid`.
- **ExtensionMembers**: from `pg_depend` where `deptype = 'e'` and
  `refclassid = 'pg_catalog.pg_extension'::regclass`: columns
  `class_label, objid, refobjid` where `class_label` is a `CASE classid`
  producing one of `type`, `class`, `proc`, `operator`, `cast`, `namespace`,
  `collation`,
  else `other`. Use `'pg_catalog.pg_type'::regclass` etc. in the CASE.
- **Types**: from `pg_type t JOIN pg_namespace n ON n.oid = t.typnamespace`
  (filter) `LEFT JOIN pg_class c ON c.oid = t.typrelid`
  `LEFT JOIN pg_range r ON r.rngtypid = t.oid`
  `LEFT JOIN pg_range mr ON mr.rngmultitypid = t.oid`. Columns:
  `oid, typname, typnamespace, typtype, typcategory, typispreferred,
  (typcollation <> 0) AS collatable, typarray, typelem,
  (typsubscript = 'pg_catalog.array_subscript_handler'::regproc) AS is_array,
  typrelid, c.relkind, typbasetype, typtypmod, typnotnull,
  r.rngsubtype, r.rngmultitypid, mr.rngtypid AS multirange_of,
  (SELECT count(*) FROM pg_constraint k WHERE k.contypid = t.oid AND k.contype = 'c') AS check_count`.
  `ORDER BY oid`.
- **EnumLabels**: `enumtypid, enumsortorder, enumlabel` `ORDER BY enumtypid, enumsortorder`.
- **Relations**: `oid, relname, relnamespace, relkind, reltype, reloftype,
  (CASE WHEN relkind IN ('v','m') THEN pg_get_viewdef(oid, true) END) AS viewdef` from
  `pg_class` joined with the filter, `WHERE relkind IN ('r','v','m','f','p','S')`
  `ORDER BY oid`.
- **Attributes**: `attrelid, attnum, attname, atttypid, atttypmod, attnotnull,
  atthasdef, (attgenerated <> '') AS generated, NULLIF(attidentity, '') AS identity`
  from `pg_attribute a JOIN pg_class c ON c.oid = a.attrelid` with the filter,
  `WHERE attnum > 0 AND NOT attisdropped AND relkind IN ('r','v','m','f','p','S','c')`
  `ORDER BY attrelid, attnum`.
- **Functions**: `oid, proname, pronamespace, prokind, provariadic,
  pronargdefaults, prorettype, proretset, proisstrict, provolatile,
  proargdefaults::text` with the
  filter, `ORDER BY oid`.
- **FunctionArguments**: one row per argument:
  ```sql
  SELECT p.oid::text, a.n::text, a.t::text, m.mode::text, nm.name::text
  FROM pg_proc p JOIN pg_namespace ns ON ns.oid = p.pronamespace  -- filter
  CROSS JOIN LATERAL unnest(coalesce(p.proallargtypes, p.proargtypes::oid[])) WITH ORDINALITY AS a(t, n)
  LEFT JOIN LATERAL unnest(p.proargmodes) WITH ORDINALITY AS m(mode, n) ON m.n = a.n
  LEFT JOIN LATERAL unnest(p.proargnames) WITH ORDINALITY AS nm(name, n) ON nm.n = a.n
  ORDER BY p.oid, a.n
  ```
  `mode` NULL means `In`. `name` NULL or empty string means no name.
- **Aggregates**: `aggfnoid, aggkind, aggnumdirectargs` `ORDER BY aggfnoid`.
- **Operators**: `oid, oprname, oprnamespace, oprkind, oprleft, oprright,
  oprresult, oprcode, oprcom, oprnegate` with the filter, `ORDER BY oid`.
- **Casts**: `oid, castsource, casttarget, castfunc, castcontext, castmethod`
  `ORDER BY oid`.
- **DefaultOperatorClasses**: `c.oid, opcname, amname, opcintype, amopstrategy,
  amopopr` from `pg_opclass c JOIN pg_am am ON am.oid = c.opcmethod` with the
  filter on `opcnamespace`, `JOIN pg_amop o ON o.amopfamily = c.opcfamily AND
  o.amopmethod = c.opcmethod AND o.amoplefttype = c.opcintype AND
  o.amoprighttype = c.opcintype AND o.amoppurpose = 's'`,
  `WHERE c.opcdefault AND am.amname IN ('btree','hash')`
  `ORDER BY c.oid, o.amopstrategy`. Cross-type family members
  (`amoplefttype <> amoprighttype`) are not read.
- **PrimaryKeys**: `conrelid, condeferrable, n, attnum` from `pg_constraint k
  JOIN pg_class c ON c.oid = k.conrelid` with the filter on `relnamespace`,
  `CROSS JOIN LATERAL unnest(k.conkey) WITH ORDINALITY AS a(attnum, n)`,
  `WHERE k.contype = 'p'` `ORDER BY conrelid, n`. One row per key column.
- **Inherits**: `inhrelid, inhseqno, inhparent` from `pg_inherits i JOIN
  pg_class c ON c.oid = i.inhrelid` with the filter on `relnamespace`,
  `WHERE c.relkind IN ('r','v','m','f','p','S')` (this drops the partitions of
  an index) `ORDER BY inhrelid, inhseqno`.
- **Rules**: `oid, ev_class, rulename, ev_type, is_instead,
  (ev_qual::text = '<>') AS unconditional, ev_enabled,
  pg_get_ruledef(oid, true) AS definition` from `pg_rewrite r JOIN
  pg_class c ON c.oid = r.ev_class` with the filter on `relnamespace`,
  `WHERE NOT (rulename = '_RETURN' AND ev_type = '1')` and the relation
  relkinds, `ORDER BY ev_class, rulename`.
- **Triggers**: `oid, tgrelid, tgname, tgtype, tgenabled` from `pg_trigger t
  JOIN pg_class c ON c.oid = t.tgrelid` with the filter on `relnamespace`,
  `WHERE NOT tgisinternal` and the relation relkinds,
  `ORDER BY tgrelid, tgname`.
- **Parameters**: `name, vartype` from `pg_settings` `ORDER BY name`. No value.
- **Collations**: `oid, collname, collnamespace, collprovider,
  collisdeterministic, collencoding` from `pg_collation` with the filter on
  `collnamespace`, `ORDER BY oid`. The Types query also gives `typcollation`
  and the Attributes query also gives `attcollation`.
- **Constraints**: `oid, conrelid, conname, contype, condeferrable, n, attnum`
  from `pg_constraint k JOIN pg_class c ON c.oid = k.conrelid` with the filter
  on `relnamespace`, `LEFT JOIN LATERAL unnest(k.conkey) WITH ORDINALITY AS
  a(attnum, n) ON true`, `WHERE conrelid <> 0` and the relation relkinds,
  `ORDER BY conrelid, conname, n`. One row per column; one row with NULLs for a
  constraint with no column.
- **OperatorClasses**: `oid, opcname, opcnamespace, amname, opcintype,
  opcdefault` from `pg_opclass c JOIN pg_am am ON am.oid = c.opcmethod` with
  the filter on `opcnamespace`, each access method, `ORDER BY oid`.
  ExtensionMembers also knows `pg_opclass` as `opclass`.

Every query is a `&'static str` in `loader/queries.rs` with a comment
listing its column indexes. `loader/queries.rs` owns the `QueryId` enum and
`pub fn sql(id: QueryId) -> &'static str`; `loader/mod.rs` re-exports
`QueryId`. `loader/queries.rs` has no `use` of anything else in the crate. Validate each query against PostgreSQL 14, 15,
16, and 17 in Docker (`postgres:14`, `:15`, `:16`, `:17`).

### Assembly policy (`loader/build.rs`)

1. Schemas: all rows.
2. Extensions: rows whose `extnamespace` is a loaded schema; else
   `MissingReference` and skip.
3. Extension membership map `(class_label, Oid) -> Handle<Extension>`.
3a. Collations: keep when the schema is loaded (else `MissingReference`) and
   `collprovider` is one of `d c i b` (else `UnparsableValue`). Handles are in
   OID order. A type or a column whose collation is not kept stays, with
   `collation = None` and a `MissingReference` to the collation.
4. **Types, kept set.** Start with every row. Remove a type when:
   `typtype` not in `b c d e p r m` (`UnknownTypeKind`); schema not loaded;
   composite whose `relkind` is not in `r v m f p c` (silent, by design);
   or, iterated to a fixpoint, any referenced type is not kept
   (`MissingReference`): array element, `typarray` when non-zero, domain
   base, range subtype and multirange, multirange's range, and every
   attribute type of a composite. Arrays: `is_array` decides; `typelem` on a
   non-array is ignored. `typarray = 0` gives `array: None`.
5. **Relations, kept set.** Rows whose schema is loaded and whose `reltype`
   is a kept type. A sequence (`relkind` `S`) has `reltype = 0`, so only its
   schema decides, and its `row_type` is `None`. A relation's columns are the
   Attributes rows for its OID; all their types are kept by step 4, since the
   row type is a composite. The columns of a sequence are `int8` and `bool`;
   a column whose type is not kept gives `MissingReference` and goes. A
   column whose `attidentity` is not `a`, `d`, or NULL gives `UnparsableValue`
   and goes: the two kinds accept different values, so a guess is not safe.
6. Assign handles: sort each kept set by OID; handle = position.
7. Build types and relations. A composite type gets
   `relation = Some(h)` when `relkind` in `r v m f p` and that relation is
   kept, else `None`. Fields and Columns come from the same Attributes rows.
8. Functions: keep when schema loaded and every argument type, the return
   type, and `provariadic` (when non-zero) are kept; else `MissingReference`.
   Aggregates attach from the Aggregates rows.
9. Operators: keep when schema loaded, `oprcode <> 0` (else `Skipped`
   `ShellOperator`), the function is kept, and left (when non-zero), right,
   result types are kept. Commutator and negator resolve to `None` when they
   point at a non-kept operator, with a `MissingReference`.
10. Casts: keep when source and target are kept and, for method `f`, the
    function is kept.
10a. Default operator classes: group the rows by class OID. Drop the class
    with a `MissingReference` (entity `OperatorClass`) when `opcintype` or any
    `amopopr` is not kept. A btree class needs strategies 1 to 5, else
    `Skipped` with `IncompleteOperatorClass`; it sets `Type::btree`. A hash
    class sets `Type::hash_equality` from strategy 1. When two classes are the
    default for one type and one access method, the lower OID wins.
10b. Primary keys: group the rows by `conrelid`, in `n` order. A relation
    takes its key in step 7. A key of a relation that is not kept goes away
    with no note, because the relation already has one. A key goes away, also
    with no note, when one of its columns is not a column of the relation (the
    column already has a `MissingReference`): a part of a key would let a
    consumer accept a `GROUP BY` that the server rejects.
10c. Typed tables: `of_type` is the handle of `reloftype` when it is not 0.
    When that type is not kept, the relation stays with `of_type = None` and
    a `MissingReference` (entity `Relation`, referenced `Type`).
10d. Parents: a relation takes its `Inherits` rows in step 7, in `inhseqno`
    order. A parent that is not kept gives a `MissingReference` (entity
    `Relation`, referenced `Relation`) and goes; the other parents stay.
10e. Default types: `loader/node_tree.rs` reads the text of `proargdefaults`.
    It splits the top-level list into nodes (a backslash escapes a brace) and
    reads the result type of each node from one field at the top level of the
    node: `CONST :consttype`, `FUNCEXPR :funcresulttype`, `OPEXPR`,
    `DISTINCTEXPR`, `NULLIFEXPR :opresulttype`, `RELABELTYPE`, `COERCEVIAIO`,
    `ARRAYCOERCEEXPR`, `COERCETODOMAIN`, `FIELDSELECT`, `CONVERTROWTYPEEXPR
    :resulttype`, `ARRAY`/`ARRAYEXPR :array_typeid`, `SUBSCRIPTINGREF
    :refrestype`, `CASE`/`CASEEXPR :casetype`, `COALESCE`/`COALESCEEXPR
    :coalescetype`, `MINMAX`/`MINMAXEXPR :minmaxtype`, `ROW`/`ROWEXPR
    :row_typeid`, `SQLVALUEFUNCTION :type`, `PARAM :paramtype`; `BOOLEXPR`,
    `NULLTEST`, `BOOLEANTEST`, `SCALARARRAYOPEXPR` give `bool`. PostgreSQL 16
    renamed some labels, so both forms are read. Another label gives `None`.
    When the text does not parse, or does not hold `pronargdefaults`
    expressions, each entry is `None`. No diagnostic: `None` already says
    that the type is not known.
10f. Rules and triggers: a relation takes its rows in step 7, sorted by the
    bytes of the name. A rule with an `ev_type` other than `2 3 4`, and a rule
    or a trigger with a firing letter other than `O R A D`, gives
    `UnparsableValue` (entity `Rule` or `Trigger`) and goes. A row of a
    relation that is not kept goes with no note.
11. Extension attribution: `type` for types, `class` for relations, `proc`
    for functions, `operator` for operators, `cast` for casts, `namespace`
    for schemas.
10g. Constraints: group the rows by constraint OID, in `n` order. A `contype`
    other than `p u c f x t` gives `UnparsableValue` (entity `Constraint`) and
    the constraint goes. The columns stay as the server gave them. A relation
    takes its constraints in step 7, sorted by the bytes of the name.
10h. Operator classes: keep when the schema and `opcintype` are kept, else
    `MissingReference` (entity `OperatorClass`). Handles are in OID order.
11a. Parameters: `vartype` maps to `ParameterKind { Bool, Integer, Real,
    String, Enum }`. Another `vartype` gives `UnparsableValue` (entity
    `Parameter`, OID 0, the value names the parameter) and the parameter goes.
12. Push everything into `CatalogBuilder` in handle order and `finish`.
    Cycles (composite <-> relation, type <-> array) are closed by pushing
    with handles computed in step 6; nothing is patched afterwards.
